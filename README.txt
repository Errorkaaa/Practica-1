Открыть: Android Studio -> File -> Open -> выбрать папку Practica1.
Дождаться Gradle Sync (нужен интернет, скачается Gradle 8.7 и зависимости).
Если студия предложит обновить Android Gradle Plugin - можно согласиться или отказаться, работает и так.
Запуск: Run 'app' на эмуляторе или телефоне. LogCat: фильтр MainActivity.
